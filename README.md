# Word Blaster

A spelling arcade game by ZetaQ LogiQ. Words fall from space; some are spelled wrong.
Tap the misspelled words to blast them before they land. Longer words score more.
Three levels: Rookie, Explorer and Champion.

**Play:** https://zetaq-logiq.github.io/word-blaster/

Works on phones, tablets and computers. Everything is in one file, `index.html`, so you can
host it on any static web server. It needs internet only for Google Fonts, and it falls back to
system fonts if they can't load. The best score is kept in the player's own browser.
